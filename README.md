# Atividade — Colaboração e Commits no GitHub

## Objetivo

Esta atividade tem como objetivo demonstrar o funcionamento da colaboração em um repositório do GitHub, realizando commits a partir de diferentes usuários.

## Descrição da atividade

Para realizar a atividade, foi utilizado um repositório criado por uma das integrantes da equipe. A outra integrante foi adicionada como colaboradora do repositório.

Após a configuração da colaboração, foram realizados commits utilizando as contas dos dois usuários.

Dessa forma, foi possível verificar no histórico do GitHub os commits realizados individualmente por cada integrante.

## Atividades realizadas

- Utilização de um repositório compartilhado no GitHub;
- Adição de uma integrante como colaboradora;
- Realização de commit pela proprietária do repositório;
- Realização de commit pela colaboradora;
- Envio das alterações para o repositório remoto utilizando `git push`;
- Verificação do histórico de commits no GitHub.
